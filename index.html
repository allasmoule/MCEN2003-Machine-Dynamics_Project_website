    Linear motion

    • v = ds/dt    a = dv/dt
    • Δv = ∫ a dt    Δs = ∫ v dt
    • v = u + at  constant a
    • Δs = ut + ½at²
    • v² = u² + 2aΔs

    Rotational motion

    • ω = dθ/dt    α = dω/dt
    • ω = ω₀ + αt
    • θ = ω₀t + ½αt²
    • ω² = ω₀² + 2αθ
    • 1 rpm = 2π/60 rad/s

    Circular motion

    • v = rω
    • at = rα
    • an = v²/r = rω²
    • s = rθ  arc length

    Relative & polar

    • sA = sB + sA/B
    • vr = ṙ    vθ = rθ̇
    • ar = r̈ − rθ̇²
    • aθ = rθ̈ + 2ṙθ̇

    Maths you'll need

    • ax² + bx + c = 0
    • x = (−b ± √(b²−4ac)) / 2a
    • c² = a² + b² − 2ab·cos C
    • a / b = sin A / sin B

    Constants & conversions

    • g = 9.81 m/s²
    • km/h → m/s: ÷ 3.6
    • rpm → rad/s: × 2π/60
    • rad → rev: ÷ 2π
